# 外婆的旧皮箱 · 未寄出的京话

南京鼓楼 · 1949 · 一个网页解谜游戏。

**在线玩：** https://yadnuses.github.io/gulou-old-suitcase/

![扫码玩鼓楼](qr-game.png)

## 故事

1949 年，一个南京女人把五个地方写进一本书。她没有寄出去。  
七十七年后，你打开她留下的旧皮箱，替她走一遍。

## 五个点位

- 下关 · 中山码头
- 静海寺 · 天妃宫
- 颐和路 · 十二片区
- 阅江楼
- 先锋书店 · 五台山店

## 怎么玩

从 `index.html` 开始，或直接进入 `京话.html` 封面。  
按故事顺序一路解谜；也可以从章节导航任选一页。  
建议手机横屏或桌面浏览器；所有页面为静态 HTML，无需后端。

## 技术

- 纯静态 HTML / CSS / JavaScript
- 无需登录、无需下载、无需后端
- 进度与交互在浏览器内完成
- 字体通过公共 CDN 加载，离线时会回退到系统字体
